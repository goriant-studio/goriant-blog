// turbo-all

1. Stage all changes:
```bash
git add -A
```

2. Show what will be committed:
```bash
git status
```

3. Commit with a descriptive message summarizing the changes:
```bash
git commit -m "<descriptive message>"
```

4. Push to remote:
```bash
git push
```
