# Blog Best Practices

This skill provides the standard practices for the Goriant Blog project. 
Always consult these rules when generating or modifying blog code, layouts, components, or content.

## When to Use This Skill
- Creating new Astro pages or layouts
- Creating UI components
- Writing Tailwind CSS classes
- Writing or translating Markdown (`.md`) blog content
- Structuring the bilingual content schema (en/vi)

## Guidelines

1. **Astro Structure & Components**
   Refer to `./rules/astro-guidelines.md` for rules on Astro project structure, component reuse, and routing.

2. **Tailwind CSS Styling**
   Refer to `./rules/tailwind-styling.md` for dark mode rules, responsive design rules, and class ordering.

3. **Markdown Content & i18n**
   Refer to `./rules/markdown-content.md` for translating pages, writing frontmatter, and standardizing blog content.
