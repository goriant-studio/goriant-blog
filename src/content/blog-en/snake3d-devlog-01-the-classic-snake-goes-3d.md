# **🐍 Dev Log #1 – Snake3D: The Classic Snake Goes 3D**

## **👋 A New Game is Born**

Hi there 👋

After working on MazeEscape, I wanted to push myself into a new territory — **3D game development in the browser**.

The result? **Snake3D** — a modern 3D take on the classic snake game, built entirely with **Three.js**.

---

## **❓ Why Snake3D?**

The classic snake game is:

- Simple to understand
- Fun to play
- A great learning project for 3D development

I wanted to explore:

- 🧊 **3D rendering** with Three.js
- 🎮 **Game mechanics** in 3D space
- ✨ **Visual effects** like lighting, shadows, and smooth animations

> Taking something familiar and giving it a fresh 3D perspective felt like the perfect challenge.

---

## **🛠️ Tech Stack**

For this project, I'm using:

- 🌐 **Three.js** for 3D rendering
- 🎨 **CSS** for UI overlays
- 📦 **Vanilla JavaScript** — no frameworks, pure code
- 🧩 Hosted on my **Astro blog** as a static game

No build tools needed. Just open it in a browser and play!

---

## **🧱 What's in the First Version?**

### **✅ 3D Snake**

- The snake moves through a 3D grid
- Grows longer when eating food
- Smooth movement and camera follow

### **✅ Food System**

- Randomly spawned food items
- Visual feedback when eating

### **✅ Game Over Detection**

- Self-collision detection
- Wall/boundary collision

### **✅ Score Tracking**

- Points per food eaten
- Score displayed in real-time

---

## **🤯 Challenges I Faced**

Building a game in 3D brings a whole new set of challenges:

- **Camera angles** — finding the right perspective so the game is playable
- **3D collision detection** — more complex than 2D
- **Performance** — keeping 60fps in the browser with 3D rendering
- **Controls** — making movement feel natural in 3D space

Each problem taught me something new about Three.js and game development.
